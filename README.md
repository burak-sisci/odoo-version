# odoo-version — Odoo Community tabanlı markalı ERP

Son güncelleme: 2026-10-18

> `odoo-version` geçici bir çalışma adıdır. Ürünün kalıcı adı MVP sonunda belirlenecek (D-014).

Odoo Community 20.0 (LGPL-3) üzerine kurulan, **kendi markamızla** ürün ve/veya SaaS olarak satılacak bir ERP.
- Odoo çekirdeği değiştirilmez; her şey ayrı modüllerle eklenir (D-010).
- Hedef, Odoo'daki tüm uygulamaların işlevsel karşılığını sunmak. Enterprise'a özel özellikler clean-room yöntemiyle yeniden yazılacak.
- Türkiye'ye özel e-Fatura / e-Arşiv katmanı MVP'nin parçası (D-012).

**Durum:** Faz 0 — Planlama.
- Temel kararlar alındı (D-010 … D-015).
- Sıradaki adım: kullanıcıyla detaylı planlama (T0.8).
- Açık karar: D-016 (kendi modüllerimizin lisansı).
- Henüz kod yok.
